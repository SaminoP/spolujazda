☁️ Cloud synchronizácia

Pripojenie ku Google Firebase umožňuje synchronizovať jazdy a tankovania v reálnom čase odkiaľkoľvek.
1. Vytvor bezplatný projekt: Na console.firebase.google.com.
2. V projekte aktivuj:
• Authentication → Email/Password
• Firestore Database → Create database (Test mode)
3. Vlož vygenerovanú konfiguráciu: (Projekt → Nastavenia → Vaše aplikácie → Web)
4. DÔLEŽITÉ – Trvalé pravidlá (Rules):
Aby cloud fungoval navždy bez expirázie, choď do Firestore Database → Rules a vlož: 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
Následne klikni na Publish.
