☁️ Cloud synchronizácia

Pripojenie ku Google Firebase umožňuje prihlásiť sa a synchronizovať jazdy a tankovania medzi mobilom a počítačom v reálnom čase odkiaľkoľvek.
1. Vytvor si bezplatný projekt: Na console.firebase.google.com.
2. V projekte aktivuj:
• Authentication → Email/Password
• Firestore Database → Create database (Test mode)
3. Vlož vygenerovanú konfiguráciu: (Projekt → Nastavenia → Všeobecné → Vaše aplikácie → Web)
